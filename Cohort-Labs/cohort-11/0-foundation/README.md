# Foundation: Get Set Up Before Week 1

Welcome to the AI PM Certification.

Before you build your first agent, you need a working toolkit. This foundation module gets Claude installed, running inside VS Code, and teaches you how to turn repeated prompts into reusable skills.

Every lab in the weeks ahead assumes this setup is done. Work through the lessons in order. No prior coding experience needed — just a computer and a paid Claude account.

---

## The Lessons

### [Lesson 1 — How to Set Up Claude](./how-to-setup-claude/README.md)

Install the Claude Desktop app on macOS or Windows, enable Claude Code, sign in, and pick a working folder. You'll finish by confirming that Claude can read and write files in that folder.

**You'll need:** a Claude Pro plan.

---

### [Lesson 2 — Set Up VS Code and Claude in VS Code](./setup-vscode-and-claude-in-vscode/README.md)

Set up the terminal-based workflow: subscribe, install Node.js (v18+), install Claude Code from the terminal, and run it inside a VS Code project folder. Includes troubleshooting steps for common install issues.

A shorter step-by-step reference is also available in [installation.md](./setup-vscode-and-claude-in-vscode/installation.md).

**You'll need:** a Claude Pro or Max plan, Node.js 18+, and VS Code.

---

### [Lesson 3 — Skills: Stop Rewriting Prompts, Start Running Skills](./setup-skill-in-claude/README.md)

Instead of retyping the same long prompt every time, you'll define it once as a skill and run it with a single command. You'll build three skills used throughout the course: `/market-research`, `/user-research`, and `/prd`.

You'll learn what skills are, where to store them, and what happens behind the scenes when you run one.

---

## What You'll Have at the End

- Claude Code running on your machine, on the desktop app and in VS Code
- A working project folder Claude can read and write in
- Three reusable skills for market research, user research, and PRDs
