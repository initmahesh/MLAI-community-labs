## Before you start

- Have your **Anthropic API key** ready. Each lab asks for it once.
- Lab 1 asks you to upload two contracts (the download links are in the notebook). Labs 2 and 3 use the short AWS contract.
- Do the labs in order. Lab 2 builds on Lab 1, and Lab 3 builds on Lab 2.
- Run the cells from top to bottom. Don't skip ahead.
